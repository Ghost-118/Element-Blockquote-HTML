# Element Blockquote HTML

Proyecto que demuestra la implementación correcta de etiquetas de citación e información referencial en **HTML5**. Utiliza los consejos de Quincy Larson sobre el desarrollo profesional como contenido de ejemplo para aplicar elementos semánticos de citas textuales y fuentes externas.

---

## 🚀 Características

- **Citas en Bloque:** Uso del elemento `<blockquote>` para fragmentos de texto o citas extensas.
- **Citas en Línea:** Uso del elemento `<q>` para frases breves dentro de un párrafo.
- **Atributo Cite y Etiqueta Cite:** Aplicación del atributo `cite` para enlazar las fuentes URL originales y de la etiqueta `<cite>` para referenciar títulos de obras o publicaciones.
- **Estructura Semántica:** Organización modular en secciones (`<section>`) dentro del contenedor principal (`<main>`).
